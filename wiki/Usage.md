# 使用指南

## 安装游戏版本

1. 打开 **游戏版本** 页
2. 顶部可搜索版本号（如 `1.21.1`），并按类型筛选：正式版 / 快照 / Beta / Alpha
3. 点击版本卡片上的 **安装**
4. 在弹窗中设置：
   - **实例名称**：默认 `Minecraft <版本号>`，可自定义
   - **运行加载器**：
     - **原版** — 纯净体验
     - **Fabric** — 轻量加载器，可运行 Fabric Mod 与 Iris 光影
     - **Forge** — 模组生态最全；选择后会出现 Forge 版本下拉框（标注“推荐 / 最新”），通过 Forge 官方安装器安装，需要已安装 Java，首次安装需要几分钟
5. 点击 **开始安装**，安装任务转入后台（可在 **下载管理** 查看进度）
6. 完成后自动选为新实例，回 **首页** 点击 **启动游戏**

> 版本数据与游戏文件均来自 Mojang 官方服务器；安装会下载客户端、运行库和全部资源文件。

## 下载 Mod

1. 打开 **Mod 下载** 页
2. 顶部筛选：
   - **游戏版本**：默认为你当前实例的版本，强烈建议保持一致
   - **加载器**：Fabric / Forge / NeoForge / Quilt，需与实例加载器匹配
3. 点击资源卡片查看详情，在发布版本列表中选择一个版本
4. 点击 **下载到 Mods 文件夹**，文件自动保存到当前实例的 `mods\` 目录
5. 重启游戏即可加载

> 常见错误：把 Forge Mod 放进 Fabric 实例、或游戏版本不匹配，会导致游戏无法加载 Mod。筛选器就是为了避免这种情况。

## 下载光影

1. 打开 **光影下载** 页
2. 建议先按当前游戏版本筛选
3. 下载后文件保存到当前实例的 `shaderpacks\` 目录
4. 进入游戏 → 设置 → 视频设置 → 光影包，选择下载的光影文件

> 光影需要 Iris（Fabric）或 OptiFine 支持才行。Fabric 实例可在 Mod 页搜索安装 **Iris**；原版实例无法加载光影。

## 实例管理

- 首页右上角点击当前实例卡片，或在实例卡片区域切换
- 每个实例拥有独立的：存档（`saves`）、Mod（`mods`）、光影（`shaderpacks`）和版本文件
- 实例弹窗中可以：
  - **切换**当前实例
  - **打开实例文件夹**（资源管理器）
  - **删除实例**：整个实例目录移入系统回收站，可在回收站恢复

## 下载管理与失败日志

- **下载管理** 页显示所有任务：进度、已下载大小、取消按钮
- 下载/安装失败时：
  - 提示信息会注明“失败日志已生成”
  - 失败任务旁出现 **失败日志** 按钮，点击直接打开日志文件
  - 日志路径：`D:\HCL\data\logs\error.log`，包含时间、任务、URL、保存位置与错误详情
- 安装失败的半成品实例目录会自动移入回收站，不会残留垃圾文件

## 设置页

| 设置项 | 说明 |
| --- | --- |
| 外观主题 | 6 套强调色主题（绿/蓝/紫/橙/粉/青），点击立即生效并保存 |
| 玩家名称 | 离线模式下游戏内显示的名字，建议 3–16 位字母/数字/下划线 |
| Java 路径 | 留空自动检测；也可浏览选择 `java.exe` |
| 游戏内存 | 默认 4 GB；大型整合包可适当增加 |
| 游戏目录 | 实例与资源文件的保存位置，默认 `D:\HCL\data\games` |

修改后点击 **保存设置** 生效。
