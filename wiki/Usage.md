# 使用指南

主界面左侧导航：**首页 / 游戏版本 / Mod 下载 / 光影下载 / 下载管理 / 联机 / 设置**。

## 安装游戏版本

1. 打开 **游戏版本** 页
2. 顶部可搜索版本号（如 `1.21.1`），按类型筛选：正式版 / 快照 / Beta / Alpha
3. 点击版本卡片上的 **安装**
4. 在弹窗中设置：
   - **实例名称**：默认 `Minecraft <版本号>`，可自定义
   - **运行加载器**：
     - **原版** — 纯净体验
     - **Fabric** — 轻量加载器，可运行 Fabric Mod 与 Iris 光影
     - **Forge** — 模组生态最全；选择后出现 Forge 版本下拉框（标注“推荐 / 最新”），由 Forge 官方安装器完成安装
5. 点击 **开始安装**，任务转入后台，可在 **下载管理** 查看进度
6. 完成后自动选为新实例，回 **首页** 点击 **启动游戏**

> 版本数据与游戏文件均来自 Mojang 官方服务器；Forge 版本列表与安装器在官方源失败时自动切换 BMCLAPI 国内镜像；Fabric 下载失败同样有镜像兜底。

## Java 自动匹配

无需任何配置：启动时启动器自动按实例匹配 Java（1.16.5 以下→8、1.17–1.20.4→17、1.20.5+→21），本机没有就自动从 Adoptium 下载（国内走清华镜像），装完自动继续启动。详见 [[安装指南|Installation]]。

## 下载 Mod

1. 打开 **Mod 下载** 页
2. 顶部筛选：
   - **游戏版本**：默认当前实例版本，强烈建议保持一致
   - **加载器**：Fabric / Forge / NeoForge / Quilt，需与实例加载器匹配
3. **支持中文搜索**：直接输入中文（如“创造模式、一键挖矿、小地图”），启动器会自动翻译为英文关键词在 Modrinth 检索；资源卡片和详情页会显示已收录的中文名称与中文简介
4. 点击资源卡片查看详情，在版本列表中选择一个版本
5. 点击 **下载到 Mods 文件夹**，文件自动保存到当前实例的 `mods\` 目录
6. 重启游戏即可加载

> 常见错误：把 Forge Mod 放进 Fabric 实例、或游戏版本不匹配，会导致 Mod 无法加载。筛选器就是为了避免这种情况。部分 Mod 需要前置（如 Fabric API），详情页会提示。

## 下载光影

1. 打开 **光影下载** 页，建议先按当前游戏版本筛选
2. 下载后文件保存到当前实例的 `shaderpacks\` 目录
3. 进入游戏 → 设置 → 视频设置 → 光影包，选择下载的光影文件

> 光影需要 **Iris**（Fabric）或 **OptiFine** 支持。Fabric 实例可在 Mod 页搜索安装 Iris；原版实例无法加载光影。

## 实例管理

- 首页右上角点击当前实例卡片切换 / 新建
- 每个实例拥有独立的：存档（`saves`）、Mod（`mods`）、光影（`shaderpacks`）和版本文件
- 实例弹窗中可以：**切换**、**打开实例文件夹**、**删除实例**（整个目录移入系统回收站，可恢复）

## 游戏账户

打开 **设置 → 游戏账户**，支持两类账户：

| 类型 | 说明 |
| --- | --- |
| 离线模式 | 直接输入玩家名创建，适合单机或允许离线的服务器 |
| 皮肤站账户 | Yggdrasil 外置登录（如 [LittleSkin](https://littleskin.cn)），进入开启外置登录的在线服务器时验证正版身份 |

**添加皮肤站账户**：

1. 在 [littleskin.cn](https://littleskin.cn) 注册账号并创建角色（皮肤站账户通用流程，其他 Yggdrasil 站点选「自定义」填 API 根地址）
2. 启动器 **设置 → 游戏账户 → 添加账户 → 皮肤站账户**，选择 LittleSkin，输入账号密码登录
3. 多个账户可随时切换，启动游戏时使用当前选中的账户

> 密码仅用于向认证服务器登录，不会保存在本机。Microsoft 正版登录暂未支持（需要 Azure 应用注册，后续版本考虑）。

## 和朋友联机

打开 **联机** 页：

**局域网联机**（同一 Wi-Fi / 路由器）：

1. 游戏内按 ESC → 「对局域网开放」，端口会显示在聊天框
2. 页面会列出本机局域网 IP，一键复制
3. 朋友在多人游戏中输入 **你的IP:端口** 即可加入

**跨网络联机（cpolar 内网穿透）**，三步：

1. 点击 **下载** 隧道程序（约 8 MB，cpolar 官网国内直连；已装过 cpolar 官方客户端会自动复用）
2. 点 **打开后台** 注册 cpolar 免费账号，在「验证」页复制 authtoken 粘贴进启动器（保存一次，后续免填）
3. 游戏内「对局域网开放」后，把聊天框显示的端口填进启动器，点 **启动隧道**

页面会自动显示公网地址（如 `6.tcp.cpolar.top:12345`），点 **复制地址** 发给朋友，对方在多人游戏 **直接连接** 输入即可。

> 免费版隧道地址每次重启会变化，重新启动隧道会自动刷新显示；退出启动器时隧道自动关闭。

## 下载管理与失败日志

- **下载管理** 页显示所有任务：游戏安装、Mod/光影、Java 运行时、启动器更新都有独立图标与进度
- 下载/安装失败时：失败任务旁出现 **失败日志** 按钮，点击直接打开日志（`D:\HCL\data\logs\error.log`）
- 安装失败的半成品实例目录会自动移入回收站，不留垃圾文件
- 启动器更新任务完成后可直接点 **重启安装**

## 启动器更新

- 默认自动：启动时检查 + 运行中每 4 小时复查，发现新版本后台下载，右下角弹卡片一键 **立即重启** 安装
- 侧栏底部版本号可点击手动检查；**设置 → 启动器更新** 可关闭自动更新

## 外观主题

**设置 → 外观主题**：6 套强调色（翡翠绿 / 穹际蓝 / 星辉紫 / 暖阳橙 / 樱花粉 / 薄荷青），点击色卡立即生效并保存，窗口背景随主题联动。

## 设置页总览

| 设置项 | 说明 |
| --- | --- |
| 玩家名称 | 离线模式下游戏内显示的名字（3–16 位） |
| 游戏语言 | 自动设为简体中文（v1.4.1+），可关闭 |
| 游戏账户 | 离线 / 皮肤站账户管理与切换 |
| 外观主题 | 6 套强调色即时切换 |
| Java 环境 | 检测结果、重新检测、手动指定路径、内存分配、**自动下载缺失的 Java** 开关 |
| 存储位置 | 游戏目录修改、数据目录打开 |
| 启动器更新 | 自动检查并下载更新开关、关于卡片手动检查 |
