# HCL 启动器 Wiki

欢迎来到 **HCL** 的官方 Wiki。HCL 是一个简洁的 Minecraft 启动器：官方版本下载、Modrinth Mod/光影下载、原版与 Fabric 实例管理，所有数据保存在 D 盘。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 游戏版本下载 | Mojang 官方版本源，支持正式版 / 快照 / Beta / Alpha |
| Mod 下载 | Modrinth 资源，按游戏版本与加载器筛选，直下到实例 `mods` |
| 光影下载 | Modrinth 光影资源，保存到实例 `shaderpacks` |
| 实例管理 | 原版 / Fabric / Forge 实例，独立存档、Mod、光影 |
| 外观主题 | 6 套强调色主题一键切换，即时生效 |
| 应用内更新 | 自动检查 + 手动入口（首页/侧栏/设置），发现新版主动提示 |
| 游戏账户 | 离线 / 皮肤站账户（LittleSkin 等 Yggdrasil 外置登录），多账户切换 |
| 联机 | 局域网 IP 一键复制 + playit.gg 内网穿透隧道 |
| 下载管理 | 后台多任务、进度、取消、失败日志 |
| 启动设置 | 离线玩家名、内存、Java 检测与自定义路径 |
