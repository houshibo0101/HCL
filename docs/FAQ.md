# 常见问题（FAQ）

## 启动相关

### 提示“未检测到 Java”怎么办？

1. 打开 **设置 → Java 环境**，点击 **重新检测**
2. 仍未检测到时，点击 **获取 Java 21** 下载安装（Adoptium Temurin），装完回来重新检测
3. 或点击 **浏览** 手动选择已安装的 `java.exe`

Minecraft 1.20.5 及以上建议 Java 21；较新版本建议 Java 17。

### Windows SmartScreen 拦截安装包？

安装包未做代码签名。点击 **更多信息 → 仍要运行** 即可。

### 启动后闪退 / 无响应？

- 确认内存分配不超过物理内存（设置页可调）
- 确认 Java 版本与游戏版本匹配（见上）
- Fabric 实例放了不兼容的 Mod（Forge Mod / 版本不符）会启动失败，移出不兼容 Mod 再试

## 下载相关

### 下载失败（404 / 网络错误）怎么办？

1. 打开 **下载管理**，失败任务旁点击 **失败日志**
2. 日志在 `D:\HCL\data\logs\error.log`，包含失败 URL 与具体原因
3. 网络波动导致的失败直接重新点安装即可；已下载完整的文件会跳过，不重复下载

### 下载速度慢？

- HCL 直连 Mojang / Modrinth 官方源，网络环境不同速度差异较大
- 可稍后在网络空闲时重试；任务支持取消后重新下载

### Mod 下载了但游戏里没生效？

按顺序检查：

1. 实例加载器与 Mod 加载器是否匹配（Fabric 实例只能用 Fabric Mod）
2. 游戏版本是否与 Mod 支持版本一致（下载时按版本筛选可避免）
3. 文件是否在实例的 `mods\` 目录（可在实例弹窗打开目录确认）
4. 部分 Mod 需要前置 Mod（如 Fabric API），一并下载

### 光影不显示？

光影需要 **Iris**（Fabric）或 **OptiFine**。Fabric 实例先去 Mod 页安装 Iris，再在游戏内 视频设置 → 光影包 启用；原版实例无法加载光影。

## 存储相关

### 游戏文件在哪？

默认在 `D:\HCL\data\games\instances\<实例>\`。首页实例卡片 / 实例弹窗可一键打开目录。

### 可以换到其他盘吗？

可以。**设置 → 存储位置 → 游戏目录** 修改保存；只影响之后新建的实例。

### 删除实例后存档还能找回吗？

删除实例是把整个目录移入 **系统回收站**，在回收站里可以还原。

## 其他

### HCL 是官方启动器吗？

不是。HCL 是社区制作的第三方启动器，与 Mojang / Microsoft 无隶属关系；游戏文件从 Mojang 官方服务器下载，Mod/光影来自 Modrinth。
