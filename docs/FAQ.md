# 常见问题（FAQ）

## 更新相关

### HCL 怎么更新？

- **自动更新**（默认开启）：启动时自动检查，运行中每 2 小时复查一次；发现新版本自动后台下载（进度在「下载管理」可见），完成后右下角弹出更新卡片，点 **「立即重启」** 几秒钟完成安装；不点也没关系，退出应用时照常自动装
- 侧栏底部版本号可点击手动检查；也可在 **设置 → 关于** 里检查
- 可在 **设置 → 启动器更新** 一键关闭自动更新
- **v1.0.0（早期安装）没有更新模块**：请从 [Releases](https://github.com/houshibo0101/HCL/releases) 手动下载 v1.1.0 或更新版本安装一次，之后就全自动了
- 应用内更新基于 GitHub Releases；**v1.7.1 起支持国内镜像**，**v1.7.4 起自动区分国内外**：探测 GitHub 直连质量，国外直连官方源、国内自动走镜像（gh-proxy 等），互为兜底，全程无需手动操作
- **v1.7.5 起镜像并行竞速 + jsDelivr CDN 双保险**：多个镜像同时探测取最快，版本元数据另有 jsDelivr 通道，镜像站轮换失效也不影响更新
- 仍可随时手动下载安装包覆盖安装
- macOS 暂不支持应用内自动更新（需要签名），会提示手动下载

### 更新下载了一半失败？

重新点侧栏版本号检查更新即可，已下载部分会重新校验；不影响当前版本的使用。

## 启动相关

### 提示“未检测到 Java”怎么办？

- **v1.6.3 起一般不用手动装**：启动游戏时自动匹配该版本需要的 Java（1.16.5 及以下→8，1.17–1.20.4→17，1.20.5+→21），缺失时自动从 Adoptium 下载安装（国内走清华 TUNA 镜像），下载完自动继续启动
- 安装 Forge 时缺 Java 也会自动补齐
- 自动下载可在 **设置 → Java 环境 → 自动下载缺失的 Java** 关闭
- 仍想手动配置：**设置 → Java 环境** 点击 **重新检测**，或 **浏览** 选择已安装的 `java.exe`（手动指定优先级最高）

### 自动下载的 Java 装在哪？

`D:\HCL\data\runtime\java-8 / java-17 / java-21`（无 D 盘机器在 `%APPDATA%\HCL\data\runtime`）。删除对应目录即可卸载，下次启动会重新下载。

### 快照版 / 老版本启动失败？

- 快照版对 Java 要求可能高于正式版，启动器会按版本信息自动匹配
- 很老的版本（Beta / Alpha）在 Java 8 上即可运行；若遇到问题可手动指定低版本 Java
- Fabric 实例放了不兼容 Mod（Forge Mod / 版本不符）会启动失败，移出后重试

### Windows SmartScreen 拦截安装包？

安装包未做代码签名。点击 **更多信息 → 仍要运行** 即可。

### macOS 提示“已损坏，无法打开”？

应用未做 Apple 公证签名。终端执行 `xattr -cr /Applications/HCL.app` 后重新打开；或右键 → 打开。

### 启动后闪退 / 无响应？

- 确认内存分配不超过物理内存（设置页可调）
- Java 版本与游戏版本不匹配（v1.6.3 起自动匹配，一般不会再遇到）
- 整合了不兼容的 Mod，先清空 `mods\` 目录验证

### 不小心点开了两次启动器？

v1.7.13 起启动器是单实例的：重复启动只会把已有窗口唤到前台，不会再开第二个进程，`settings.json` / `instances.json` 不会被两个进程同时改写。

## 联机相关

### 朋友连不上我的世界？

按顺序检查：

1. 同一 Wi-Fi：确认朋友输入的是 **局域网 IP:端口**（联机页一键复制），且游戏已「对局域网开放」
2. 跨网络：确认隧道已启动且页面显示公网地址；朋友要用 **直接连接** 输入 `host:端口` 完整地址
3. 游戏内「对局域网开放」的端口每次都可能变化，要用聊天框里显示的那个端口
4. Windows 防火墙首次会弹窗，选择「允许访问」

### cpolar 隧道地址为什么老变？

免费版分配的是随机地址，每次重启隧道（或重启启动器）都会变化。把启动器里显示的最新地址重新发给朋友即可；固定地址需要 cpolar 付费套餐。

### 联机延迟高 / 掉线？

- cpolar 免费版有带宽限制，模组多的服务器数据量大时会明显卡顿，建议轻量游玩
- 地区可在 cpolar 后台选择（如 China VIP 需付费）
- 局域网联机不受影响，同一个屋里的朋友直连即可

## 账户相关

### 皮肤站账户是什么？

Yggdrasil 外置登录：第三方认证服务器（如 [LittleSkin](https://littleskin.cn)）提供的账户体系，可以拥有正版身份验证、自定义皮肤披风，用于进入开启外置登录的服务器。注册免费，在启动器 **设置 → 游戏账户 → 添加账户** 登录。

### 密码安全吗？

密码只用于向认证服务器发起登录请求，**不会保存在本机**；保存的只有登录成功后的会话令牌与档案信息。

### 能登录 Microsoft 正版账号吗？

暂不支持（需要注册 Azure 应用，规划中）。目前可用离线账户或皮肤站账户。

## 下载相关

### 下载失败（404 / 网络错误）怎么办？

1. 打开 **下载管理**，失败任务旁点击 **失败日志**
2. 日志在 `D:\HCL\data\logs\error.log`，包含失败 URL 与具体原因
3. 网络波动导致的失败直接重新点安装即可；已下载完整的文件会跳过，不重复下载

### 提示「文件校验失败（SHA1 不匹配）」？

v1.7.13 起，客户端、运行库和游戏资源下载完成后都会按 Mojang 官方 SHA1 校验；不匹配说明文件在传输中损坏（断线、磁盘问题、代理劫持都可能）。
直接重新点安装即可：启动器会自动删掉损坏文件重新下载。Mod / 光影同样按 Modrinth 提供的哈希校验。

### 2.0.0 升级后实例目录变小了，是不是丢文件了？

没有。2.0.0 把 `assets`（游戏资源）和 `libraries`（运行库）移到了 `data\shared\`，所有实例共用一份。首次启动会自动迁移并弹出一次性提示，迁移后实例里只保留 `versions`、`mods`、`shaderpacks`、`saves` 这些真正属于该实例的内容。

### 下载中断后要重新下整个文件吗？

不用。2.0.0 起支持断点续传：未完成的文件以 `.part` 形式保留，重新开始时会从断点继续；同一文件的并发请求会合并成一次下载。

### 下载速度慢？

- 游戏本体：Mojang 官方源；Forge / Fabric 已内置 BMCLAPI 国内镜像兜底；Java 运行时走清华 TUNA 镜像
- Mod / 光影来自 Modrinth 官方源，速度取决于网络环境，可换个时段重试
- 任务支持取消后重新下载，不重复浪费流量

### Mod 下载了但游戏里没生效？

按顺序检查：

1. 实例加载器与 Mod 加载器是否匹配（Fabric 实例只能用 Fabric Mod）
2. 游戏版本是否与 Mod 支持版本一致（下载时按版本筛选可避免）
3. 文件是否在实例的 `mods\` 目录（可在实例弹窗打开目录确认）
4. 部分 Mod 需要前置 Mod（如 Fabric API），一并下载

### 光影不显示？

光影需要 **Iris**（Fabric）或 **OptiFine**。Fabric 实例先去 Mod 页安装 Iris，再在游戏内 视频设置 → 光影包 启用；原版实例无法加载光影。

### Forge 安装失败怎么办？

- 首次安装要下载运行库，几分钟属正常；缺 Java 会自动补齐（v1.6.3 起）
- Forge 版本列表和安装器本体已走 BMCLAPI 国内镜像兜底；但 Forge 官方安装器**内部下载运行库仍走官方源**——启动器会自动复用 **Windows 系统代理**加速，网络不通时开着代理软件（系统代理模式）再安装即可
- 失败详情见失败日志（`D:\HCL\data\logs\error.log`）

## 存储相关

### 游戏文件在哪？

默认在 `D:\HCL\data\games\instances\<实例>\`。首页实例卡片 / 实例弹窗可一键打开目录。

### 可以换到其他盘吗？

可以。**设置 → 存储位置 → 游戏目录** 修改保存；只影响之后新建的实例。

### 删除实例后存档还能找回吗？

删除实例是把整个目录移入 **系统回收站**，在回收站里可以还原。

## 其他

### HCL 是官方启动器吗？

不是。HCL 是社区制作的第三方启动器，与 Mojang / Microsoft 无隶属关系；游戏文件从 Mojang 官方服务器下载，Mod/光影来自 Modrinth，Java 运行时来自 Adoptium。
